# control-statements-repository

This repository contains Python scripts that demonstrate various control statements through practical examples.

## Overview

The `control_statements` folder includes scripts that utilize loops, conditionals, and other control structures to perform specific tasks. 

### Script Details

- **`q82.py`**: This script prints a pattern of numbers in descending order using nested loops. It serves as an example of how to use loops effectively in Python.

## Usage

To run the scripts in this repository, ensure you have Python installed on your machine. You can execute the scripts from the command line as follows:

```bash
python control_statements/q82.py
```

This will run the `q82.py` script and display the output in your terminal.
